# 🎤 Voice Assistant - Quick Start Guide

## 🚀 **Get Started in 30 Seconds!**

---

### **Step 1: Say the Wake Word**

```
Say: "أبشر" or "Absher"
```

**You'll hear**: *"نعم، كيف يمكنني مساعدتك؟"*  
(Yes, how can I help you?)

---

### **Step 2: Give Your Command**

```
Say: "تجديد الهوية"
```
(Renew ID)

**The system will**:
1. Confirm: *"جاري فتح صفحة تجديد الهوية"*
2. Navigate to the ID renewal page automatically
3. You're done! ✅

---

## 🗣️ **Common Commands**

### **Quick Reference Card**

## 👀 **Visual Guide**

### **The Voice Button**

Look for the **green/gray circular button** in the bottom-right corner:

```
🔘 Gray   = Waiting (say "أبشر" to activate)
🔵 Blue   = Listening to you
🟢 Green  = Active and ready
🟠 Orange = Processing your command
```

---

## 💡 **Pro Tips**

1. **Speak clearly** but naturally
2. **Wait** for the confirmation message
3. **Say "مساعدة"** anytime for full command list
4. **Long-press** the button to see all commands
5. **Say "إلغاء"** to deactivate

---

## ❓ **Not Working?**

### **Quick Fixes**

✅ **Allow microphone** when browser asks  
✅ **Unmute** your mic  
✅ **Speak louder** or closer to mic  
✅ **Say wake word** first: "أبشر"  
✅ **Try in Chrome** or Edge for best results

---

## 🎯 **Example Flow**

```
1. You: "أبشر"
   System: "نعم، كيف يمكنني مساعدتك؟"

2. You: "المخالفات"
   System: "جاري فتح صفحة الاستعلام عن المخالفات"
   [Navigates to violations page]

3. Done! ✨
```

---

## 📱 **On Mobile?**

- **Tap** the button to activate/deactivate
- **Hold** for 0.5 seconds to see command list
- Everything else works the same!
