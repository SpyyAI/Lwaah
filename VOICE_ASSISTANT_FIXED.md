## 🎯 **How to Use (Updated):**

### **Method 1: CLICK TO TALK (Easiest)**

1. **Click** the large green button
2. **Allow microphone** when browser asks
3. **Speak** your command clearly
4. **Done!** System navigates automatically

```
Example:
Click → "تجديد الهوية" → Navigates to ID renewal
```

### **Method 2: WAKE WORD**

1. Browser will ask for microphone
2. Say "أبشر" (Absher)
3. Say your command
4. Done!

```
Example:
"أبشر" → "المخالفات" → Navigates to violations
```

### **Method 3: KEYBOARD SHORTCUTS**

- **Ctrl + M**: Activate voice
- **Ctrl + H**: Show/hide help
- **Escape**: Stop listening
